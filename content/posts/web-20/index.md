Web 2.0 is powerful enough to dominate our new life on the Internet. del.icio.us
is a shared bookmark service built on the concept of Web 2.0, and Flickr is
another good example.

Both are built around the idea of tags. We can attach a tag to a picture or a
bookmark; a tag is like a keyword that conveys the meaning of something. Before,
I could only file something under a single category. Now we can classify pictures
or bookmarks under several categories by using tags.

It's so great!
