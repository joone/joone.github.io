This was the conference celebrating the 10th anniversary of KLDP. KLDP is the acronym of Korea Linux Documentation Project, but now KLDP is a community group for free and open source software. Actually, KLDP started from a personal web site and has now grown into the largest Linux and free/open source software community in Korea. As a result, KLDP now provides a lot of Linux documentation based on a wiki system, open source project hosting, and web boards and blogs for the community.

If you are interested in F/OSS, please join this conference. For more information, click [this link](http://kldp.org/node/72979).
