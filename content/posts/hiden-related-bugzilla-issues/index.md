As you can see from the list above, Fennec has some bugs in its Hildon integration, but the Fennec team has not paid much attention to them, because they seem to be focused on implementing the UI features and the Windows Mobile port of XULRunner. As a result, the platform-specific features still have not been implemented for the Maemo platform.
