During [the WebKitGTK+ Hackfest 2011](http://live.gnome.org/Hackfests/WebKitGTK2011),
I applied accelerated compositing to WebKitGTK+ using
[Clutter](http://www.clutter-project.org/), so it started working like
[the webkit-clutter port](http://trac.webkit.org/wiki/clutter). I was finally able
to run [the same demo](http://blog.kov.eti.br/?p=214) in GtkLauncher.

This work isn't upstreamed yet, but
[my patches are getting reviewed](https://bugs.webkit.org/show_bug.cgi?id=73319).
Gustavo and Martin are helping me write better patches — thanks!

I think this hackfest went really well. You can read more about the WebKitGTK+
hackfest in other blog posts:

- <http://blogs.igalia.com/juanjo/2011/12/04/webkitgtk-hackfest-wrap-up/>
- <http://blogs.igalia.com/juanjo/2011/11/17/announcing-the-webkitgtk-hackfest-2011/>
- <http://www.hadess.net/search/label/hackfest>

I would like to thank my employer Collabora, as well as Igalia and the GNOME
Foundation, for helping us attend the hackfest. See you at the next one!
