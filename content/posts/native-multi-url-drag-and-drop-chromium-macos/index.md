date: 2026-07-08

Chromium Canary now supports native multi-URL drag-and-drop on macOS. You can
drag multiple URLs using the `text/uri-list` drag data type from Chromium and
drop them into native apps like Keynote or Pages. It also works with Safari.
This will ship in Edge/Chrome 152.

- **Change list:** [Support native multi-URL drag and drop on macOS (7774364)](https://chromium-review.googlesource.com/c/chromium/src/+/7774364)
- **Demo:** [X thread](https://t.co/cZAqvOGyBm)
