[Samsung Windows Mobile SDK 1.0 has been released!](http://news.softpedia.com/news/Samsung-Windows-Mobile-SDK-1-0-Now-Available-105829.shtml)

You can download Samsung Windows Mobile SDK 1.0 from the [SAMSUNG Mobile Innovator web site](http://innovator.samsungmobile.com/down/cnts/detail.view.do?platformId=2&cateId=147&childCateId=All&childCateId2=&cntsId=1641&imgType=&parentCateId=147&cateAll=all&listReturnUrl=http%3A%2F%2Finnovator.samsungmobile.com%3A80%2Fdown%2Fcnts%2Fcategory.main.list.do%3FplatformId%3D2%26cateId%3D147%26cateAll%3Dall&previousUrl=http%3A%2F%2Finnovator.samsungmobile.com%3A80%2Fdown%2Fcnts%2Fcategory.main.list.do%3FplatformId%3D2%26cateId%3D147%26cateAll%3Dall), but you need to register before downloading. Of course, it's free.

It consists of the API spec, a programming guide, an installation guide, header files and a library for the device APIs, and sample code.

The APIs are used to provide advanced features unique to Samsung phones. You may already have experience using the advanced capabilities offered by the Windows Mobile APIs, such as GPS, Bluetooth, or multimedia support. In addition to the Microsoft Windows Mobile APIs, you can use the Samsung device APIs to access phone features such as the accelerometer, notification LEDs, and haptic feedback.

In addition, [you can download SAMSUNG device emulator skin files from the web site](http://innovator.samsungmobile.com/down/cnts/detail.view.do?platformId=2&cateId=147&childCateId=&cntsId=1646&imgType=&parentCateId=147&cateAll=all&listReturnUrl=http%3A%2F%2Finnovator.samsungmobile.com%3A80%2Fdown%2Fcnts%2Fcategory.main.list.do%3FplatformId%3D2).

The Device Emulator skin archive contains skins for the following phones:

*   SGH-i617 BlackJack II
*   SGH-i907 Epix \[and SGH-i780 Mirage\] (I own this model)
*   SCH-i760 Robin
*   SCH-i770 Saga
*   SPH-i325 ACE
*   SGH-i900 Omnia \[and SCH-i910 Omnia\]

Device Emulator skins let you change the physical appearance of the Device Emulator in Microsoft Visual Studio. Once installed, the Samsung Device Emulator skins let you run the emulator with the appearance of a Samsung phone.
