I began working on the Servo project. Actually, [my first open source project was Mozilla](https://joone4u.blogspot.com/search/label/Mozilla), and I was also involved in the Korea Mozilla community. During that time, I contributed to the Fennec browser by [fixing bugs](https://joone4u.blogspot.com/2009/08/how-to-check-hardware-keyboard-on.html) and working on localization. Anyway, [this blog article](https://andreasgal.com/2017/07/19/firefox-marketshare-revisited/) motivated me to work on Mozilla again.

I landed [a simple patch](https://github.com/servo/servo/commit/ac877659e664897c2c2f303eb983458eab7212c7) and am working on adding [the ellipse API to the Canvas API](https://github.com/servo/rust-azure/pull/272). I see many missing features, so it looks like a blue ocean to me compared to the Chromium project.
