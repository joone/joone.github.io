I bought a Nokia N810 from Amazon. Actually, there are no shopping malls selling the N810 in Korea, so I had to buy one from an overseas store. Anyway, I am very satisfied with the N810. It may be my favorite toy.

The N810 uses the Maemo platform, which is based on Linux 2.6, GTK+, Matchbox, and other open source projects. Scratchbox is used as its development environment, providing a cross-platform development environment. So users can develop an application without knowing how to use a toolchain for specific target devices. In addition, we can easily install applications from the repositories using the Debian packaging and repository system.

I think it's a truly open mobile platform based on Linux, because [Nokia handed over the governance of Hildon to the GNOME community.](http://arstechnica.com/journals/linux.ars/2007/06/14/nokia-pushes-hildon-upstream)

First, [I'd like to build XULRunner and run Fennec (Mozilla Mobile).](https://bugzilla.mozilla.org/show_bug.cgi?id=430200) It seems that it could run on the N810 and Windows Mobile 6. So I'll check the status and give my feedback to the community.
