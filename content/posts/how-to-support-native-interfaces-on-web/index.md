[I posted an article about supporting native interfaces in Mobile Firefox.](http://joone4u.blogspot.com/2008/01/ideas-on-supporting-native-interfaces.html) By the way, I found information related to my post [here](http://www2003.org/cdrom/papers/refereed/p643/p643-barton-final.htm). This paper described the native interfaces I talked about as sensors on a device, and introduced how to send their sensed data to servers via the Web.

A sensor is a device that reads data from the user's physical environment. I am interested in how to get data from the native interfaces through a web browser. I have not yet considered how a browser sends data to a server. In any case, this paper seems useful for extending web browser technologies in a standard way.

Getting location data from a GPS sensor has already been realized in Firefox. [Doug introduced this news on his blog and implemented a prototype.](http://dougt.wordpress.com/2008/01/16/skyhook-doggone-well-2/) I think it needs to be standardized.
